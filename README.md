# Stphn-Wrn.github.io

Page qui regroupe mes modules Foundry VTT et Roll20 : https://stphn-wrn.github.io

Site statique, sans build. Pour ajouter un module, ajouter une entrée dans `modules.js` :
la version et la compatibilité sont lues en direct depuis le `module.json` du dépôt
(ou depuis la dernière release GitHub pour les scripts Roll20).

Aperçu en local :

```sh
python3 -m http.server 8000
```
